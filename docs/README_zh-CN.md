# Latria

**肉欲、信仰与王权。**

[English](../README.md)

帝国在神圣的旗帜下崛起，王朝凭借血脉与婚姻延续。然而，一扇寝宫门后的秘密，也可能动摇数代人建立的基业。

**Latria** 是《**十字军之王 III**》的性与浪漫扩展项目，着眼于欲望、虔诚与权力之间的冲突。它的愿景从统治者的私生活延伸至整个家族的命运，让爱情、禁忌的欢愉与宗教丑闻，同继承、征服和王冠的陨落一道进入历史。

君主能够号令大军，要求臣民服从。人心与肉体，却没有那么容易统治。

## 欲望与王朝

婚姻联结显赫的家族，责任却不能平息所有渴望。纹章背后的生活，也由眷恋、忠诚、嫉妒与背叛塑造。Latria 探索戴冠之人与延续王朝的责任之间的冲突，让亲密关系的后果触及家庭、声名与后世。

## 肉体与精神

肉体欢愉可以带来慰藉，放纵与克制却都可能付出代价。欲望、满足、耗竭与衰弱，让统治者在头衔之外有了自己的生活。承载王朝的身体可能成全它的希望，也可能不堪重负；寻求安宁的精神可能得到释放，也可能被无法平息的渴求吞没。

## 信仰与审判

信仰赋予欲望以美德、罪恶、责任与救赎之名。私下的选择可能违背神圣的誓言，世人的裁断也未必与统治者的信念一致。Latria 着眼于中世纪世界的诸多宗教传统，探索虔诚与欲望如何争夺同一个灵魂，以及受命审判他人的人如何面对自己的审判。

## 丑闻与王权

始于秘密的事，可能最终摆到整个领地面前。亲密关系带来信任，也暴露弱点；丑闻为敌人提供理由，宗教权威则可能将一场指控变成对统治资格的争夺。Latria 将这些冲突从寝宫与宫廷延伸至神圣权威与世俗王冠的对抗。在那里，救赎与支配可能成为同一种野心的两种名义。

## 仍在续写的历史

Latria 是一个持续发展的项目，其长期愿景是呈现更丰富的中世纪世界，让欲望、信仰与王朝野心彼此交织。后续开发将继续深化这些联系，为统治者的生涯和他们留给后世的领地带来新的视角与故事。
