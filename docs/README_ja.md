# Latria

**肉欲、信仰、支配。**

[English](../README.md) | [简体中文](README_zh-CN.md) | [Français](README_fr.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Русский](README_ru.md) | [한국어](README_ko.md) | **日本語** | [Polski](README_pl.md)

帝国は聖なる旗の下に興り、王朝は血統と婚姻によって続いていく。だが、寝室の扉の向こうに隠された秘密が、幾世代もかけて築かれたものを脅かすこともある。

**Latria** は **Crusader Kings III** の性と恋愛を描く拡張プロジェクトであり、欲望、信仰、権力のせめぎ合いを扱う。その構想は統治者の私生活から一族の命運にまで及ぶ。愛、禁じられた歓び、宗教をめぐる醜聞も、継承や征服、王冠の没落と同じ歴史の一部となる。

君主は軍を指揮し、服従を命じることができる。人の心も肉体も、そう易々とは従わない。

## 欲望と王朝

婚姻は名家同士を結びつけるが、義務だけですべての渇望が静まるわけではない。紋章の陰にある暮らしは、愛情、忠誠、嫉妬、裏切りによっても形作られる。Latria は王冠を戴く個人と、その存続を求める王朝との間にある葛藤を描き、親密な絆が家族、名声、後世に及ぼす影響を扱う。

## 肉体と精神

肉体の歓びは慰めを与えるが、放縦にも節制にも代償がある。欲望、満足、疲弊、衰弱は、称号の外にある統治者の暮らしを形作る。王朝を支える肉体は、その希望をかなえることもあれば、重みに耐えきれなくなることもある。安らぎを求める精神も、解放を得るとは限らず、自らの渇望に呑み込まれることがある。

## 信仰と審判

信仰は欲望を、美徳、罪、義務、救済という言葉で語る。私生活での選択が神聖な誓いと相容れず、世間の裁きが統治者自身の信念と食い違うこともある。Latria は中世世界のさまざまな宗教的伝統を通じ、信心と欲望がいかに同じ魂を奪い合うのか、そして他者を裁く役目を託された者たちが、自らへの裁きにどう向き合うのかを描く。

## 醜聞と王権

秘密のうちに始まったことが、やがて領国全体の知るところとなるかもしれない。親密な関係は信頼を育むと同時に、弱みをさらす。醜聞は敵に大義を与え、宗教的権威は告発を、誰に統治する資格があるのかをめぐる争いへ変えることがある。Latria はこうした対立を寝室や宮廷から、聖なる権威と世俗の王冠との衝突にまで広げる。そこでは救済と支配が、同じ野心を掲げる二つの名となることもある。

## 書き継がれる年代記

Latria は開発を続けるプロジェクトであり、欲望、信仰、王朝の野心が切り離せない、より豊かな中世世界を長期的な構想としている。今後の開発でもこれらの結びつきを掘り下げ、統治者の生涯と、その後に残される領国に、新たな視点と物語を加えていく。
